# Web3 前端面试题库

中文 Web3 前端面试题库（Web3 Frontend Interview Questions），现收录 193 道题。内容聚焦 DApp 前端实际工作中的钱包连接、签名、交易、合约交互、链上数据与安全；每题提供简答、深入分析、常见错误、追问、评分标准和参考资料，适合按主题复习与自测。

## 为什么做这个项目

最近在准备和整理 Web3 前端面试资料时，我发现现有内容普遍比较零散：有些长期没有更新，有些只有题目没有可靠答案，还有不少内容没有标注适用的技术版本。

更明显的问题是真实面经太少。我们很难知道企业实际在考察什么、会怎样追问，以及不同水平的回答差异在哪里。

因此，我想做一个持续更新、经过验证、专注于 Web3 前端的中文面试题库。它不会重复整理随处可见的通用前端基础题，而是关注钱包连接、签名、交易、合约交互、链上数据、安全和工程化等 Web3 前端特有的问题。

我也希望看到这个项目的同行，愿意在保护公司信息和个人隐私的前提下，一起分享真实面经。现在可以通过 GitHub 提交面经、题目建议和内容纠错；维护者核对并整理后再决定是否收录。

## 当前已有

- 已建立 Web3 前端题目的统一内容结构，包含难度、分类、题型、适用生态、技术版本和参考资料，并为内部审核保留扩展字段。
- 已建立题目质量模板，覆盖简要回答、深入回答、常见错误、追问和分级评分标准。
- 已实现内容自动校验，检查题目字段、章节顺序、参考资料一致性、审核元数据以及重复的 `id` 和 `slug`。
- 已支持在题目详情中记录“不清楚、待复习、已掌握”等状态，数据只保存在当前浏览器。
- 题目可收藏，并在“我的收藏”中查看；收藏只保存在当前浏览器。
- 已为未来的账号、跨设备进度、收藏和自定义题单准备数据模型，但当前不开放登录入口。
- 已完成站点基础工程和首页，现有 193 道覆盖不同难度、题型与核心领域的题目；在原有 125 道基础上，先后新增 52 道与 16 道经过筛重和修订的题目，涵盖 Passkey、Permit2、ERC-4626、预言机、私有交易和分叉调试等主题。
- 已实现题库列表和题目详情页；题库每页展示 10 道题，详情页支持上一题、下一题连续浏览；内容完整并通过自动校验的题目默认公开，不要求额外的人工审核流程。
- 题目详情默认隐藏参考答案，便于先独立作答，再按需展开简要回答、深入分析和评分标准。
- 题库支持关键词搜索，并可组合难度、分类、题型和技术栈筛选；筛选与分页条件保存在 URL 中，可以刷新或分享。
- 可在当前搜索和筛选范围内随机抽题；候选范围大于 1 时不会连续抽到同一道。
- 支持冷白、石墨和暖砂 3 种阅读主题，选择只保存在当前浏览器。
- 已开放[反馈与投稿](https://github.com/Sophran-fbj/web3-frontend-interview/issues/new/choose)：可提交内容纠错、Web3 前端题目建议和已匿名化的真实面经，收录前由维护者审核。

## 已计划的功能

### 后续阶段

- 账号登录和跨设备学习进度同步。
- 错题本、复习列表和自定义题单。
- 模拟面试、限时回答，以及按岗位和级别组织的面试套题。

- 中英文双语内容。

## 未来展望

题量会增长，但内容质量、来源可信度和持续更新始终优先。随着更多同行分享真实面经，题库也能更接近真实招聘需求，帮助准备进入 Web3 的前端工程师少走弯路，也让已经在行业中的开发者有一个可以共同沉淀经验的地方。
